## Síntesis General del Curso
Este repositorio contiene las evidencias de finalización de los Módulos 1 al 4 del curso Python Essentials 1 de la plataforma OpenEDG. Durante el desarrollo de este curso se abordaron los siguientes conceptos clave:
* **Módulo 1:** Introducción a la programación, compilación vs. interpretación y el entorno de ejecución de Python.
* **Módulo 2:** Tipos de datos, variables, operaciones básicas de entrada y salida (`print`, `input`), y operadores aritméticos.
* **Módulo 3:** Valores booleanos, control de flujo con sentencias condicionales (`if`, `elif`, `else`), estructuras de repetición (`while`, `for`) y operaciones lógicas.
* **Módulo 4:** Definición y uso de funciones, paso de parámetros, variables con alcance (scope), y estructuras de datos como listas, tuplas y diccionarios.
